This directory is for redundant and obsolete code which anyone repeating my work should not need. You can probably ignore it completely.
The code here is old scripts I wrote for development and testing purposes throughout the project.
I have retained all of the code just in case I ever need to repeat something unexpected, or in case I need to show how I did something in the future. 
Except for the code in the jasmin directory, the code here was all written specifically to run on the atmospheric servers at Cambridge University's chemistry department. 
The datasets used for some of these scripts were different to the datasets required for the up-to-date code and therefore they may not be indexed in the same way. Some of the code here therefore won't work with the up-to-date datasets or functions.
Some of the code in the shared functions and constants scripts are for these old datasets and probably won't be used again, but I left them there for consistency.
